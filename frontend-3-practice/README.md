# frontend-3-practice — Основы React

Страница «Выбор даты и времени» перенесена с HTML/CSS и нативного JavaScript на React.

## Запуск проекта

Требуется установленный Node.js (рекомендуется актуальная LTS-версия).

Откройте терминал в папке `frontend-3-practice` и выполните:

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173/`.

Проверка production-сборки:

```bash
npm run build
```

## Структура проекта

- `src/main.jsx` — точка входа React.
- `src/App.jsx` — общая структура страницы.
- `src/BookingScreen.jsx` — состояние и логика выбора даты и времени.
- `src/components/Header.jsx` — шапка сайта.
- `src/components/Footer.jsx` — подвал сайта.
- `src/components/Calendar.jsx` — календарь и навигация по месяцам.
- `src/components/TimeSlots.jsx` — список временных слотов.
- `src/components/BottomBar.jsx` — нижняя панель выбранной даты и времени.
- `src/data/date.js` — функции построения и проверки дат.
- `src/data/slots.js` — данные и доступность временных слотов.
- `src/styles.css` — стили из предыдущей практической работы.
- `public/images/` — изображения из `frontend-2-practice`.

## Реализованное поведение

- При открытии выбрана сегодняшняя дата и отображаются её слоты.
- При выборе дня календарь обновляет список слотов, а выбранное время сбрасывается.
- Выбор доступного слота отображается в нижней панели.
- Стрелки переключают месяцы.
- Даты раньше сегодняшней приглушены и недоступны для нажатия.
- Нижняя панель показывает день недели, число, месяц, год и выбранное время.

Состояние хранится в `useState`, списки строятся через `.map()`, обработчики событий назначаются через `onClick`.
