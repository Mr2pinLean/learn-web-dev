# Страница выбора даты и времени на React

Учебное задание: перенести свою страницу календаря с нативного
JavaScript на React.

---

## Что уже сделано

До этой лекции у вас была готовая страница выбора даты и времени
на HTML, CSS и чистом JavaScript.
Теперь эту же страницу нужно переписать на React.

---

## Как запустить

Нужен **Node.js** версии 18 или выше.

```bash
npm install     # установить зависимости (один раз)
npm run dev     # запустить dev-сервер
```

Vite напишет адрес — обычно `http://localhost:3000`.
Откройте его в браузере.

## Задание

Переписать страницу выбора даты и времени на React. Поведение
должно остаться тем же, что и в нативной версии.

### Что нужно изменить по сравнению с нативной версией

| Нативный JS                           | React                              |
| ------------------------------------- | ---------------------------------- |
| Переменные в глобальной области       | `useState`                         |
| `document.querySelector`, `innerHTML` | JSX                                |
| `addEventListener("click", ...)`      | `onClick` в JSX                    |
| Сборка HTML строками                  | `.map()` по массиву и JSX-элементы |
| Императивное обновление DOM           | Декларативный рендер по состоянию  |

### Что можно перенести как есть

- **Вёрстку** — тот же HTML, только вместо `class` пишем `className`,
  а самозакрывающиеся теги (`<hr>`, `<br>`, `<img>`) закрываем
  через `/>`.
- **Стили** — CSS-файлы можно положить в проект как есть. Один
  файл или несколько — на ваше усмотрение. Подключить в `main.jsx`
  или в компонентах.
- **Чистые функции для работы с датами** — те, что не трогают DOM.
  Например, построение сетки календаря, сравнение дат, форматирование.
  Их удобно положить в отдельный файл `src/utils/date.js` и импортировать
  по мере надобности.
- **Данные слотов** — если они у вас захардкожены, так и оставьте.
  Если генерируются — переносите функцию.

## Как подойти к работе

### 1. Определите, из каких компонентов будет состоять страница

Посмотрите на свою вёрстку. Скорее всего, там есть шапка, основная
область с календарём и слотами, подвал. Может быть, ещё отдельные
блоки — например, индикатор шагов или нижняя панель.

Разбейте страницу на компоненты по смыслу. Один компонент — один
файл. Названия — на ваше усмотрение.

### 2. Перенесите разметку

Каждый блок вёрстки становится компонентом. Разметка переезжает
в JSX почти без изменений. Основные отличия:

- `class` → `className`;
- `<hr>` → `<hr />`, `<br>` → `<br />`, `<input>` → `<input />`;
- атрибуты вроде `for` → `htmlFor`.

### 3. Определите, что должно быть в состоянии

Посмотрите на нативный код: там были переменные, которые менялись
при кликах. Например, текущий месяц, выбранный день, выбранное время.
Их переносите в `useState`. Обычно каждое независимое значение —
отдельный `useState`.

### 4. Замените прямые манипуляции с DOM на рендер по состоянию

Там, где в нативном коде было `element.innerHTML = ...` или
`element.classList.add(...)`, в React:

- готовите JSX для нужного вида;
- React сам обновит DOM, когда состояние изменится;
- классы собираете через `className={...}` условно.

### 5. Обработчики

Вместо `addEventListener` вешаете `onClick` прямо на JSX-элемент.
Вместо чтения `data-*` атрибутов — используете замыкание: например,
для каждого дня в `.map()` создаёте свой `onClick`, который знает
именно этот день.

## Как проверять

Откройте DevTools → **Console**. Ошибок React быть не должно.

Проверьте три сценария:

1. **Открытие страницы.** Выбран день по умолчанию, показаны его
   слоты.
2. **Клик по другому дню.** Выделение перешло, слоты обновились,
   прошлое выбранное время сброшено.
3. **Листание месяцев.** Стрелки работают. При переходе через
   декабрь/январь меняется год.

Дополнительно проверьте, что дни раньше «сегодня» не кликаются
и визуально отличаются от остальных.

## Полезные напоминания

**Ключи в списках.** Везде, где используете `.map()` для рендера
списка (дни календаря, слоты времени), ставьте `key`. Для слотов
подойдёт время (`key={slot.time}`) — оно уникально. Для дней
календаря — индекс ячейки в сетке.

**Сброс времени при смене дня.** Если пользователь выбрал время
на одном дне, а потом кликнул на другой — время нужно сбросить.
Иначе получится странный баг: в нижней панели отображается время,
которого на новом дне нет.

**Изменение состояния — только через сеттер.** Нельзя писать
`state.field = value`. React не заметит изменения. Всегда
`setState(...)` или `setState({ ...state, field: value })`.

**Условный рендер.** Внутри JSX нельзя писать `if`. Используйте
тернарник `условие ? <A /> : <B />` или логический `&&` для
«показать, если условие» (`{isLoading && <Загрузка />}`).
