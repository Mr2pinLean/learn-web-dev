# Задание 4. Асинхронный JavaScript и React

Страница выбора даты и времени на React. Дата «сегодня» и временные слоты загружаются через `fetch` с имитационного API, подключённого как плагин Vite.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Для production-сборки:

```bash
npm run build
```

## API

- `GET /api/booking/today` — возвращает `{ day, month, year }`.
- `GET /api/slots?day=&month=&year=` — возвращает `{ date, slots }`.

Месяц в API нумеруется с нуля. Формат слота: `{ time, available }`.

## Реализованные сценарии

- При открытии страницы отображается «Загрузка…», затем загружается дата с сервера и показывается календарь.
- При выборе даты отображается «Загрузка слотов…», затем показываются полученные с сервера слоты.
- Ошибки запросов отображаются понятным сообщением; доступна повторная попытка.
- При быстрых переключениях дат устаревшие ответы игнорируются: проверяются номер запроса и дата в ответе сервера.

## Где менять данные

- `server/database.js` — дата «сегодня» и два набора слотов.
- `server/server.js` — имитационный API и задержка ответа `DELAY_MS` (по условию задания файл не менялся).
- `src/api.js` — клиентские функции `fetchToday()` и `fetchSlots(date)`.
