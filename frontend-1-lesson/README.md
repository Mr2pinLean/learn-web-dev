# ÉLAIRE — страница выбора услуг

Учебный пример: одна страница сайта салона красоты с выбором услуг.
Только вёрстка (HTML + CSS). Без JavaScript, без React, без переходов
на другие страницы.

Используется на лекции, чтобы показать базовую вёрстку: как устроена
сетка, как оформляются карточки услуг, как выглядит боковая панель
с категориями и индикатор шагов.

---

## Как открыть

Двойной клик по `index.html` — страница откроется в браузере.
Никаких установок и сборки не требуется.

Если в редакторе есть **Live Server** (VS Code, WebStorm) — можно
открыть через него: правый клик по HTML-файлу → «Open with Live Server».
Тогда страница будет обновляться при изменениях.

---

## Что внутри

- **Шапка** — логотип, навигация, кнопка «Войти».
- **Боковая панель** — список категорий услуг с количеством.
- **Индикатор шагов** — три шага бронирования, активен первый.
- **Список услуг** — пять карточек с названием, описанием,
  длительностью и ценой. У каждой кнопка «Выбрать».
- **Подвал** — бренд, контактная информация, копирайт.

Никакой логики: клики по категориям, кнопкам и шагам ничего не делают.
Состояние (активная категория, активный шаг) захардкожено в разметке
через класс `active`.

## Стили

Один файл `services.css`. Внутри — секции:

- **reset & base** — сброс отступов, шрифт страницы.
- **page** — общий контейнер, flex-column, фон.
- **header** — шапка, логотип, навигация, кнопка «Войти».
- **main-booking-flow** — flex-контейнер для сайдбара и списка услуг.
- **sidebar** — список категорий: обычное состояние, hover, active.
- **services-list** — правая колонка.
- **step-indicator** — кружки, подписи, соединительные линии.
- **service-row** — карточка услуги: инфо, мета, кнопка «Выбрать».
- **footer** — подвал.

Никаких CSS-переменных, медиазапросов и утилитарных классов нет —
для учебного примера это сделано сознательно, чтобы было проще читать.

## На что смотреть

### Flexbox

Почти вся раскладка — на flexbox. Посмотри, как устроены:

- `.header` — шапка: логотип, навигация, кнопка распределены через `justify-content: space-between`.
- `.main-booking-flow` — две колонки в ряд.
- `.service-row` — блок «инфо + мета + кнопка» в ряд.
- `.footer-top` — две группы ссылок распределены через `space-between`.

### Состояния элементов

- `.category-item:hover` — плашка подсвечивается при наведении.
- `.category-item.active` — тёмный фон для выбранной категории.
- `.circle.empty` — кружок неактивного шага: прозрачный, с рамкой.
- `.select-btn:hover` — кнопка темнеет при наведении.

### Классы `active` и `empty`

Активные состояния заданы в разметке явно. Например, в сайдбаре:

```html
<div class="category-item active">
  <span class="cat-name">Маникюр и педикюр</span>
  <div class="count-badge"><span>8</span></div>
</div>
```

Класс `active` — это то, что в реальном приложении управлялось бы JS:
пользователь кликнул — подсветилась другая категория. Здесь эта логика
не реализована — чтобы показать именно вёрстку.

### Фиксированные размеры

У `.sidebar` жёстко задана ширина `228px`. У `.rows` — `min-width: 800px`.
У `.service-row .info` — `min-width: 500px`. Эти размеры рассчитаны так,
чтобы при переключении категорий (в реальном приложении) контент
не «прыгал». Пока категории не переключаются — но размеры уже на месте.

## Что можно взять в свой проект

- **Всю разметку и стили** — если у вас похожий макет (сайдбар со списком,
  карточки услуг).
- **Классы для состояний** — `.active`, `:hover`, `.empty` как приём.
- **Подход к flexbox-раскладке** — вместо таблиц или `float`.

Если макет другой — смотрите на структуру и принципы, а не копируйте
один в один. Названия классов могут быть любые, главное — чтобы они
отражали суть.
