Учебный проект: сайт салона красоты с онлайн-записью на нативном
JavaScript. Показывает, как связать несколько HTML-страниц
в один сценарий: выбор услуги → выбор даты и времени → подтверждение
записи → модалка.

Используется на лекции и как справочник для самостоятельной работы.

---

## Как открыть

Проект не требует сборки. Откройте любой HTML-файл двойным кликом —
он запустится в браузере.

Для удобства лучше использовать **Live Server** в VS Code
или WebStorm: правый клик по HTML-файлу → «Open with Live Server».
Тогда страница обновляется автоматически при изменениях, и переходы
между страницами работают стабильно.

Файлы, с которых начинается сценарий:

- `index.html` — главная;
- `services.html` — выбор услуги;
- `booking.html` — выбор даты и времени;
- `confirmation.html` — подтверждение и модалка.

## Структура JS-файлов

Каждый JS-файл разбит на блоки — так проще понять, что где искать:

```
// 1. ДАННЫЕ, КОТОРЫЕ ПРИХОДЯТ С СЕРВЕРА
// 2. СОСТОЯНИЕ ДЛЯ СТРАНИЦЫ
// 3. ЛОГИКА ДЛЯ ИМИТАЦИИ РАБОТЫ С СЕРВЕРОМ
// 4. ЧИСТЫЕ ФУНКЦИИ
// 5. ОТРИСОВКА И ОБРАБОТЧИКИ
// + ИНИЦИАЛИЗАЦИЯ
```

Не на каждой странице есть все блоки. Например, на главной только
обработчики кликов, а на странице услуг — данные и отрисовка.
Блоки — это способ думать: «что здесь вообще есть?»

## Как передаются данные между страницами

В многостраничном приложении каждая страница — отдельный HTML-файл
со своим JavaScript. Память между ними не сохраняется. Чтобы данные
«дожили» до следующего шага, используется `localStorage`.

Сценарий:

1. На `services.html` клик «Выбрать» → объект услуги сохраняется
   в `localStorage` под ключом `elair-booking`.
2. На `booking.html` клик «Далее» → к тому же объекту дописываются
   `date` и `time`.
3. На `confirmation.html` данные читаются из `localStorage`
   и подставляются в детали визита и в модалку.
4. После подтверждения записи `localStorage` очищается.

Если открыть `confirmation.html` напрямую, не выбрав услугу и время, —
сработает защита и вернёт на `services.html`.

## На что смотреть в коде

### `services.js`

- Как рендерится список категорий и услуг через `innerHTML`.
- Как после каждой перерисовки заново вешаются обработчики
  на кнопки «Выбрать».
- Функция `formatPrice` — пример чистой функции, которую можно
  скопировать в любой проект.

### `booking.js`

- Функция `buildCalendarGrid(year, month)` — строит сетку календаря
  на нужный месяц. Чистая функция, не зависит от DOM.
- Функции `compareDates` и `isDateSelectable` — сравнение дат
  и проверка «не раньше сегодня».
- Рендер календаря через сборку HTML-строки.
- Переключение месяцев с переходом через границу года
  (декабрь → январь, январь → декабрь).

### `confirmation.js`

- Чтение данных из `localStorage`.
- Работа с нативным `<dialog>`: `showModal()` и `close()`.
- Функции `formatDateTime` и `formatDateTimeShort` — две версии
  одной даты для разных мест.

### `home.js`

- Пример самой короткой страницы: только два обработчика клика,
  без данных и состояния.

## Что можно скопировать в свой проект

Следующие функции не зависят ни от DOM, ни от данных салона.
Берёшь и вставляешь как есть.

| Функция                              | Где                              | Что делает                                       |
|--------------------------------------|----------------------------------|--------------------------------------------------|
| `buildCalendarGrid(year, month)`     | `booking.js`                     | Строит сетку календаря на месяц                  |
| `compareDates(date1, date2)`         | `booking.js`                     | Сравнивает две даты                              |
| `isDateSelectable(day, month, year)` | `booking.js`                     | Проверяет, можно ли выбрать день                 |
| `formatPrice(price)`                 | `services.js`, `confirmation.js` | Форматирует цену: `3200 → "3 200 ₽"`             |
| `formatDateTime(date, time)`         | `confirmation.js`                | Форматирует дату: `"17 октября 2026 в 12:00"`    |
| `formatDateTimeShort(date, time)`    | `confirmation.js`                | То же, но компактнее: `"17 октября 2026, 12:00"` |

Массивы `MONTHS_NOMINATIVE`, `MONTHS_GENITIVE`, `DAYS_OF_WEEK`
в `booking.js` тоже можно взять как есть, если у вас русскоязычный
проект.

## Работа с датами

Дата в проекте хранится как `{ day, month, year }`, где месяц
0-индексный (0 = январь, 9 = октябрь) — так же, как в `new Date()`.
Это удобно: не надо ничего конвертировать при передаче в `Date`.

Слоты времени хранятся как `{ time: "10:00", available: true }` —
время строкой, доступность булевым. Так проще рендерить кнопки
и различать доступные/занятые слоты.
