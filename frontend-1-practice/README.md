# Практика: вёрстка страницы выбора даты и времени

Учебное задание: сверстать одну страницу по своему макету.
Только HTML и CSS. Без JavaScript, без сборщиков, без зависимостей.

---

## Как открыть

Двойной клик по `index.html` — страница откроется в браузере.
Никаких установок не требуется.

Если в редакторе есть **Live Server** (VS Code, WebStorm) — можно
открыть через него: правый клик по HTML-файлу → «Open with Live Server».
Тогда страница будет обновляться автоматически при изменениях.

Один HTML-файл и один CSS-файл. Пока пустые — их нужно заполнить.

## Задание

Сверстать страницу выбора даты и времени по своему макету.

### Что должно быть на странице

Если в вашем макете какие-то элементы отсутствуют — реализовывать
их не нужно. Ориентируйтесь на свой макет, а не на список ниже.

Обычно на такой странице есть:

- **Шапка** — логотип, навигация, кнопка входа.
- **Индикатор шагов** — несколько шагов бронирования, один из них
  текущий. Например: «Выбор услуги», «Дата и время», «Подтверждение».
- **Календарь** — сетка дней месяца. Названия дней недели сверху,
  числа в ячейках.
- **Стрелки переключения месяцев** — вперёд и назад.
- **Блок со слотами времени** — список кнопок с временами. У некоторых
  должна быть видна пометка «занято» или визуальное отличие.
- **Нижняя панель** — показывает выбранную дату и время, и кнопка
  «Далее».

### Что нужно сделать

1. Разметить структуру страницы в `index.html`.
2. Написать стили в `styles.css`.
3. Убедиться, что вёрстка соответствует вашему макету:
   цвета, шрифты, отступы, размеры.

### Что НЕ нужно делать

- **Писать JavaScript.** Это задание только по вёрстке. Клики,
  выбор дня, переключение месяцев — не работают. Это тема
  следующей практики.
- **Подключать фреймворки или библиотеки.** Только чистый
  HTML и CSS.
- **Использовать устаревшие подходы** — таблицы для раскладки,
  `float` для позиционирования. Используйте flexbox или grid.

## Чек-лист

Проверьте себя перед сдачей:

- Размеры, цвета, шрифты и отступы соответствуют макету.
  Небольшие отклонения для кнопок и ссылок допустимы.
- Вёрстка семантическая — используются `<header>`, `<main>`,
  `<footer>`, `<section>`, `<nav>`.
- Стили вынесены в отдельный файл, инлайн-стилей нет.
- Использован flexbox для раскладки.
- У всех HTML-тегов есть классы, и для них прописаны стили.
- У активных элементов (кнопок, дней, слотов) есть визуальная
  реакция на наведение: `:hover` меняет цвет или тень.
- На кликабельных элементах курсор меняется на «лапку»
  (`cursor: pointer`).
- Занятые слоты времени визуально отличаются от свободных
  (например, серые, полупрозрачные).

## Полезно знать

### Семантические теги

Не `<div>` на всё подряд. Используйте:

- `<header>` — шапка;
- `<nav>` — навигация;
- `<main>` — основное содержимое;
- `<section>` — смысловой блок;
- `<aside>` — боковая колонка;
- `<footer>` — подвал.

### Flexbox для раскладки

Почти вся раскладка такой страницы — flexbox. Примеры:

- Шапка: `display: flex; justify-content: space-between; align-items: center;`
- Две колонки (календарь и слоты): `display: flex; gap: 40px;`
- Сетка дней календаря: `display: grid; grid-template-columns: repeat(7, 1fr);`
- Кнопки слотов: `display: flex; flex-wrap: wrap; gap: 12px;`

### Состояния элементов через классы

Активные элементы (выбранный день, активный шаг) помечаются
классом прямо в разметке. Например:

```html
<div class="day-cell selected">17</div>
```

В CSS описываете `.day-cell.selected` — и день подсвечивается.
Никакого JS пока не нужно — активные состояния захардкожены.

## Как проверять

Откройте страницу в браузере и сравните с макетом. Откройте
DevTools (`F12`) → **Elements** — посмотрите, какие стили
применяются. Если что-то не так, поправьте в `styles.css`.

Типичные проблемы:

- **Стили не применяются** — проверьте, что путь в `<link rel="stylesheet">`
  правильный.
- **Шрифты не те** — подключите через `<link>` в `<head>` или
  `@import` в CSS.
- **Элементы съезжают** — проверьте `display: flex` у родителя.
