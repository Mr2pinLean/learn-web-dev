# Практика 2 — JavaScript

Страница выбора даты и времени для барбершопа «Чёрная борода».

## Запуск
Откройте `index.html` в браузере или запустите через Live Server.

## Файлы
- `index.html` — разметка страницы.
- `styles.css` — оформление.
- `script.js` — логика календаря, выбора даты и времени.
- `images/` — изображения макета.

## Реализовано
- автоматический выбор сегодняшней даты и первого доступного времени;
- переключение месяцев;
- блокировка прошедших дат;
- обновление доступных слотов при выборе дня;
- выбор времени и обновление нижней панели;
- отображение дня недели, числа, месяца, года и времени;
- кнопка «Далее» с проверкой выбранной даты и времени.

Слоты демонстрационные и хранятся в массиве `BASE_SLOTS` в `script.js`.
