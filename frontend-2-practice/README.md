# Практика: оживить страницу календаря на нативном JavaScript

Учебное задание: взять свою свёрстанную страницу и добавить
ей интерактивность на чистом JavaScript. Без фреймворков,
без сборщиков, без зависимостей.

---

## Как открыть

Двойной клик по `index.html` — страница откроется в браузере.

Рекомендую **Live Server** в VS Code или WebStorm: страница
будет обновляться при изменениях. Иначе после каждой правки
придётся нажимать `F5` вручную.

## Задание

Оживить свою страницу выбора даты и времени.

### Что обычно должно работать

1. **При открытии страницы** сразу выбран день по умолчанию,
   показаны его слоты. Не пустой экран.
2. **Клик по дню** — день становится выбранным. Слоты обновляются
   под этот день. Если раньше было выбрано время, оно сбрасывается.
3. **Клик по слоту** — время становится выбранным, попадает
   в нижнюю панель.
4. **Стрелки «‹» и «›»** — листают месяцы вперёд и назад.
5. **Дни раньше «сегодня»** — не кликаются и выглядят приглушённо.
6. **Нижняя панель** — обновляется при выборе дня или времени.
   Показывает, например: «Пятница, 17 октября 2026 • 12:00».

### Что готово

- **Вёрстка** — из прошлой практики.
- **Стили** — те же. Возможно, понадобится добавить пару классов
  для состояний (например, `.selected`, `.disabled`), если их
  ещё нет.
- **Функция `buildCalendarGrid(year, month)`** — в `script.js`,
  в комментарии. Можно скопировать в рабочую часть файла и
  использовать. Она строит сетку календаря: принимает год и месяц,
  возвращает массив недель по 7 ячеек.

### Что нужно сделать самому

- Массив слотов — захардкодьте прямо в `script.js`.
- Состояние страницы — текущий месяц, выбранный день, выбранное
  время, слоты. Можно хранить в переменных или в одном объекте.
- Функции отрисовки календаря и слотов.
- Обработчики кликов.
- Логику «нельзя выбирать прошлое».

## Как организовать код

Разделите `script.js` на части комментариями:

```
// 1. ДАННЫЕ
//    - массив слотов;
//    - «сегодня» (захардкожено или из new Date()).

// 2. СОСТОЯНИЕ
//    - переменные, которые меняются при кликах.

// 3. ЧИСТЫЕ ФУНКЦИИ
//    - построение сетки календаря;
//    - сравнение дат;
//    - проверка «не раньше сегодня».

// 4. ОТРИСОВКА И ОБРАБОТЧИКИ
//    - функции, которые рисуют календарь и слоты;
//    - функции, которые реагируют на клики.

// 5. ИНИЦИАЛИЗАЦИЯ
//    - что вызывается один раз при загрузке страницы.
```

Это разделение — не догма, но помогает не запутаться. Чистые
функции можно копировать в другой проект — они не зависят
от DOM.

## Подсказки

### Как строить календарь

В `script.js` есть готовая функция `buildCalendarGrid(year, month)`.
Скопируйте её в рабочую часть. Она возвращает массив недель:

```js
[
  [{ day: 28, otherMonth: true }, ..., { day: 4, otherMonth: false }],
  [{ day: 5, otherMonth: false }, ...],
  ...
]
```

- `day` — число месяца.
- `otherMonth` — `true`, если день из соседнего месяца
  (например, «28» в начале, если месяц начинается со среды).

Дальше вы проходитесь по этому массиву и генерируете HTML.
`otherMonth: true` — серый и некликабельный.

### Как рендерить через innerHTML

Классический приём в нативном JS:

```js
const container = document.querySelector(".grid-days");
let html = "";
weeks.forEach((week) => {
  html += '<div class="week-row">';
  week.forEach((cell) => {
    html += `<div class="day-cell">${cell.day}</div>`;
  });
  html += "</div>";
});
container.innerHTML = html;
```

После вставки HTML **заново вешайте обработчики** на новые элементы.
Старые удалились вместе со старым HTML.

### Как понять, куда кликнули

Добавьте к каждой ячейке `data-` атрибут:

```js
html += `<div class="day-cell" data-day="${cell.day}">${cell.day}</div>`;
```

В обработчике читайте:

```js
const day = parseInt(event.currentTarget.dataset.day);
```

### Как сбрасывать время при смене дня

Не забывайте: если пользователь выбрал время на одном дне, а потом
кликнул на другой — время нужно обнулить. Иначе получится баг:
в нижней панели показывается время, которого на новом дне нет.

```js
function onDayClick(event) {
  const day = parseInt(event.currentTarget.dataset.day);
  state.selectedDay = day;
  state.selectedTime = null; // обязательно
  // ... перерисовать
}
```

### Как защитить прошлые дни

Функция для сравнения дат:

```js
function compareDates(a, b) {
  const d1 = new Date(a.year, a.month, a.day);
  const d2 = new Date(b.year, b.month, b.day);
  if (d1 < d2) return -1;
  if (d1 > d2) return 1;
  return 0;
}
```

Проверка «не раньше сегодня»:

```js
const isSelectable = compareDates(cellDate, today) >= 0;
```

Если `false` — добавляйте класс `disabled` и не вешайте
обработчик клика.

### Как строить слоты

```js
slots.forEach((slot) => {
  let classes = "time-slot";
  if (!slot.available) classes += " unavailable";
  if (slot.time === state.selectedTime) classes += " selected";

  html += `<button class="${classes}" data-time="${slot.time}">${slot.time}</button>`;
});
```

На клик — читаете `event.currentTarget.dataset.time`, сохраняете
в состояние, перерисовываете.

## Как проверять

Откройте DevTools → **Console**. Ошибок JS быть не должно.

Проверьте три сценария:

1. **При открытии** сразу выбран день по умолчанию и его слоты.
2. **Клик по другому дню** — выделение переходит, слоты обновляются,
   время сбрасывается.
3. **Листание месяцев** — стрелки работают, при переходе через
   декабрь/январь меняется год.

Дополнительно:

- Дни раньше «сегодня» — не кликаются и выглядят приглушённо.
- Нижняя панель обновляется при выборе дня и времени.

## Если что-то не работает

### Клики не срабатывают после перерисовки

Потому что вы не перевесили обработчики после `innerHTML`. Старые
элементы удалились, обработчики пропали. После каждой перерисовки
заново вызывайте функцию, которая навешивает `addEventListener`.

### Не тот день становится выбранным

Скорее всего, замыкание. Если пишете `forEach(... cell => { btn.onclick = () => onClick(cell.day); })`
— это правильно, у каждого элемента свой `cell`. Если используете
общую переменную — она «перезапишется» к моменту клика.

Проще всего — через `data-` атрибуты и `event.currentTarget.dataset`.

### Ошибка `Cannot read property of null`

Функция пытается найти элемент, которого нет на странице. Проверьте
`querySelector` — селектор написан правильно? Элемент точно есть
в HTML? Может быть, скрипт выполняется раньше, чем DOM построен —
подключайте `<script>` в конце `<body>`.
