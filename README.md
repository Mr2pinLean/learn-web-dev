# Основы web-разработки — модуль Frontend

Учебный репозиторий по frontend-разработке. Четыре темы, идущие
последовательно: вёрстка → нативный JavaScript → React → работа
с сервером.

---

## Структура

Для каждой темы — три папки:

| Папка | Что внутри |
|---|---|
| `frontend-N-practice` | Задание студенту: README и заготовка |
| `frontend-N-lesson` | Пример, разобранный на лекции |
| `frontend-N-complete` | Полное приложение целиком |

Где `N` — номер темы: 1, 2, 3 или 4.

---

## Темы

**`frontend-1` — Вёрстка**
HTML и CSS. Страница «Выбор даты и времени» по своему макету.
Без JavaScript.

**`frontend-2` — Нативный JavaScript**
Та же страница, оживлённая на чистом JS: клики, переключение
месяцев, выбор слота.

**`frontend-3` — React**
Перевод страницы на React: компоненты, `useState`, JSX. Запуск
через Vite.

**`frontend-4` — React + сервер**
Подключение имитационного сервера: данные приходят через `fetch`,
появляются состояния загрузки и ошибки.

---

## Как пользоваться

1. Открой папку своей темы — например, `frontend-2-practice`.
2. Прочитай `README.md` внутри — там задание.
3. Работай в этой папке.
4. Если что-то непонятно — загляни в `frontend-2-lesson` (пример
   с лекции) или `frontend-2-complete` (готовое приложение).

---

## Предметная область

В примерах — запись клиента в салон услуг. Это не обязательная
тема: у каждого свой макет и своя предметная область. Пример
показывает **как** решать задачи, а не **что** писать.

---

## Требования

- Node.js 18+ — для тем 3 и 4.
- Браузер — для тем 1 и 2.
